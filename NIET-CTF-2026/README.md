
# NIET CTF 2026 — Technical Writeups

A collection of my cybersecurity challenge writeups, documenting the
investigation process, technical concepts, tools, and lessons learned
while participating in NIET CTF 2026.

## About This Repository

This repository records my hands-on learning in Capture The Flag (CTF)
competitions. My goal is to understand why a challenge works, reproduce
the solution, and explain the underlying security concepts rather than
simply collect flags.

## My Approach

For each challenge, I aim to document:

1. The problem statement and objective
2. Initial observations and evidence
3. The vulnerability or weakness identified
4. The solution methodology
5. Commands and scripts used
6. The result and technical explanation
7. Key takeaways and further learning
